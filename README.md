# 应用商店数据预警看板 Demo

这是一个可离线直接打开的静态作品集 Demo。页面内置模拟数据，不连接任何真实业务系统。

## 在线预览

将 `index.html` 上传到 GitHub 仓库根目录，并启用 GitHub Pages，即可获得公开访问地址。

## 演示范围

- 应用商店日报 / 月报切换
- 预警数量趋势与状态分布
- 指标明细、筛选与搜索
- 预警原因展示
- 预警复盘填写与本地浏览器保存

## 数据与脱敏说明

- 所有指标数值、周期数据、预警状态和触发原因均为模拟数据。
- 应用名称使用按类别构造的虚拟名称，不对应真实软件清单。
- 数据源路径为通用演示名称，不包含内部 Qlik 报表路径。
- 阈值为本 Demo 为展示预警效果重新设定的演示阈值，不是原业务阈值，也不代表生产环境配置。
- 页面不包含真实账号、内部链接、真实业务数据或后端接口。

## 本地打开

下载 `index.html` 后，使用 Chrome 或 Edge 双击打开即可，无需安装环境或启动服务。
