# 应用商店数据预警看板 Demo

在线体验：[点击打开预警看板](https://Judy-918.github.io/store-alert-dashboard-demo/)

## 项目介绍

在实习期间，我独立负责商业化业务中应用商店及 OTT 业务的预警自动化工作，利用脚本将数据监测流程设计为自动化运行机制，并通过飞书自定义机器人消息推送及时反馈异常指标。

在完成实习项目后，我希望进一步探索自动化数据的可视化应用，因此基于原有业务场景独立制作了这个预警看板 Demo，将分散的预警结果集中呈现，可以实现帮助业务人员更直观地了解指标变化、识别异常并开展后续排查和复盘。

本项目为个人延伸实践，已做脱敏处理使用模拟数据和重新设定的演示阈值，不连接原业务系统。

## 项目价值

- 提升异常识别效率：将分散的预警信息集中展示，减少人工逐条查看和筛选的成本。
- 辅助业务判断：通过预警趋势、状态分布和指标明细，帮助业务人员快速了解异常发生情况及影响范围。
- 支持异常排查：展示指标变化幅度和预警触发原因，为后续定位问题提供参考。
- 沉淀复盘记录：支持填写异常原因、处理措施和复盘结果，方便记录异常处理过程。

## 核心功能

- 日报 / 月报切换： 按不同统计周期查看监测数据。
- 预警概览：展示预警数量趋势及正常、预警、数据缺失等状态分布。
- 指标明细：支持按应用、指标和状态筛选，并通过搜索定位具体记录。
- 预警原因展示：查看指标变化情况及对应的触发原因。
- 异常复盘：支持填写复盘信息，并保存在当前浏览器本地。
- 后续可以接入其他业务线数据，实现多业务线预警看板合集。

## 数据与脱敏说明

- 所有指标数值、周期数据、预警状态和触发原因均为模拟数据。
- 应用名称使用按类别构造的虚拟名称，不对应真实软件清单。
- 数据源路径使用通用演示名称，不包含真实内部路径。
- 阈值为本 Demo 重新设定的演示阈值，不是原业务阈值，也不代表生产环境配置。
- 页面不包含真实账号、内部链接、真实业务数据或后端接口。

## 本地运行

下载 `index.html`，使用 Chrome 或 Edge 浏览器直接打开即可，无需安装额外环境或启动服务。
